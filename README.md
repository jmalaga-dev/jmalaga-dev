### 🚀 Featured project

#### [beverage-factory-erp](https://github.com/jmalaga-dev/beverage-factory-erp) — Full-stack ERP for a beverage factory

A comprehensive management system migrating a legacy Excel/VBA process into a
proper layered architecture. Built solo in ~4 weeks.

- **31-table PostgreSQL schema** with full referential integrity at the DB level
- **22 domain-driven REST API routers** (FastAPI + SQLAlchemy), atomic
  transactions, `Decimal`-exact monetary math via Pydantic v2
- Real business logic: **chained costing, FIFO batch selection, weighted-average
  valuation, idempotent period closings, priority-based financial allocation**
- **React** frontend (21 screens) · **Power BI** reporting · fully **dockerized**
- ▶️ Runs with a single `docker compose up --build` (ships with demo data)
